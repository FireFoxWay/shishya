01

One neuron

A neuron takes a few numbers in and gives one number out. It does this in two steps.

  1. Weighted sum. Multiply each input by its weight, add them up, then add the bias: z = w₁x₁ + w₂x₂ + … + wₙxₙ + b.
  2. Activation. Pass z through a function f to get the output: a = f(z).

That's all a neuron does. A neural network is many of these wired together, and learning means adjusting the weights and biases until the outputs come out right.

Weights

A weight says how much one input matters, and in which direction. A large positive weight means “this input pushes the output up a lot”. A negative weight pushes it down. A weight near zero means the neuron mostly ignores that input.

Bias

The bias is added at the end and doesn't depend on any input. It sets how easily the neuron fires: a large positive bias makes it fire even on weak inputs; a negative bias makes it demand strong evidence. Many textbooks draw the bias as a weight on an extra input that is always 1, which is what the dashed node below shows.

With two inputs you can see this geometrically. The neuron splits the plane along the straight line where z = 0. The weights set the line's angle. The bias slides the line without turning it. Without a bias the line would always pass through (0, 0).

On the exam
Why do neurons need a bias? Without one, z = 0 whenever every input is 0, so the decision boundary has to pass through the origin. The bias lets the neuron move its threshold anywhere, just like the intercept c in y = mx + c lets a line sit anywhere.







  
02
The perceptron

  
The perceptron (Rosenblatt, 1958) is the oldest neural network: one neuron with a step activation. It outputs 1 if z ≥ 0 and 0 otherwise, so it answers yes or no.

  
It learns with a simple rule. Show it one example at a time. If its answer is right, change nothing. If it's wrong, nudge each weight in the direction that would have helped:


error = y − ŷ                (target minus output: +1, 0 or −1)
wᵢ  ←  wᵢ + η · error · xᵢ
b   ←  b  + η · error

  
η (eta) is the learning rate: how big each nudge is. If a straight line can separate the two classes, this rule is guaranteed to find one in a finite number of steps. That's the perceptron convergence theorem.

Now try XOR. Its output is 1 when exactly one input is 1. Look at the four points: no single straight line can put both blue points on one side and both orange points on the other. Minsky and Papert made this point in 1969 and it helped stall neural-network research through the 1970s. The fix is a hidden layer, which you can watch working in the playground.

03
Activation functions

  
The activation function f decides what a neuron outputs for a given z. Its one essential job is to be non-linear.

  
Why non-linear? If every neuron were linear, extra layers would add nothing. Two linear layers W₂(W₁x + b₁) + b₂ simplify to (W₂W₁)x + (W₂b₁ + b₂), which is a single linear layer. A hundred linear layers can still only draw a straight line. Non-linear activations are what let a network bend its decision boundary.

What is the sigmoid's derivative at z = 0? σ(0) = 0.5, so σ′(0) = 0.5 × (1 − 0.5) = 0.25. That's the largest it ever gets, which is the root of the vanishing gradient problem in section 9.







  
04
Layers and the forward pass

  
Neurons are arranged in layers. In a dense (fully connected) layer, every neuron receives every output of the layer before it.

  
    
    
  • Input layer: just the raw numbers. It has no weights and no activation.
    • 
    
  • Hidden layers: everything between input and output. They're called hidden because their values never appear in the data.
    • 
    
  • Output layer: produces the prediction.
    • 
  

  
Working out the output from the input is called the forward pass. For a whole layer at once it's one matrix multiplication:


a⁽ˡ⁾ = f( W⁽ˡ⁾ · a⁽ˡ⁻¹⁾ + b⁽ˡ⁾ )

  
W⁽ˡ⁾ has one row per neuron in layer l and one column per value coming in from layer l − 1. So a layer of 3 neurons fed by 2 inputs has a 3 × 2 weight matrix and 3 biases.

  
Worked example


x = [1, 2]

W = [  0.5   −1   ]      b = [ 0   ]
    [  1      0.5 ]          [ 1   ]
    [ −0.5    0.25]          [ 0.5 ]

z = Wx + b = [  0.5·1 + (−1)·2  + 0   ]   [ −1.5 ]
             [  1·1   + 0.5·2   + 1   ] = [  3   ]
             [ −0.5·1 + 0.25·2  + 0.5 ]   [  0.5 ]

a = ReLU(z) = [0, 3, 0.5]

05
Sizing a network: inputs, hidden layers, neurons

  
Designing a network means choosing three sizes. The data decides two of them for you. Only the hidden layers are a real choice.

  
Input layer: one neuron per feature

  
Count the numbers that describe one example. That's the input layer; there's no choice involved.

  
    
    
  • A house described by floor area, bedrooms, age and distance to the city: 4 inputs.
    • 
    
  • A 28 × 28 grayscale image: 28 × 28 = 784 inputs, one per pixel, after flattening the grid into a single list.
    • 
    
  • A 32 × 32 colour image: 32 × 32 × 3 = 3,072 inputs, because every pixel has a red, green and blue value.
    • 
    
  • A category such as colour ∈ {red, green, blue}: one-hot encode it into 3 inputs, so red is [1, 0, 0] and blue is [0, 0, 1]. Don't feed it as 1, 2, 3; that tells the network blue is “three times” red.
    • 
  

  
Scale numeric inputs to similar ranges first, for example to mean 0 and standard deviation 1. Otherwise a feature measured in thousands drowns out one measured in fractions.

  
Output layer: set by the task

Hidden layers: how many?

  
    
    
  • 0 hidden layers if a straight line (or flat plane) separates the classes. That's a perceptron, or logistic regression.
    • 
    
  • 1 hidden layer can in principle approximate any continuous function, given enough neurons. This is the universal approximation theorem. It handles most simple curved boundaries.
    • 
    
  • 2 hidden layers often learn complicated boundaries with far fewer neurons than one very wide layer. A common choice for tabular data.
    • 
    
  • More layers (a “deep” network) pay off when the data has a hierarchy, like edges → shapes → objects in an image. For images, sound and text you'd normally switch to specialised layers (section 11) rather than stack more dense ones.
    • 
  

  
How many neurons in each hidden layer?

  
No formula gives the right answer. These commonly quoted rules of thumb give a sensible place to start:

  
    
    
  • Somewhere between the size of the output layer and the size of the input layer.
    • 
    
  • About ⅔ of the input size, plus the output size.
    • 
    
  • Fewer than twice the input size.
    • 
    
  • The geometric pyramid: sizes shrink steadily from input to output. With one hidden layer that's √(n_in × n_out).
    • 
    
  • A data ceiling: total hidden neurons ≲ N / (α × (n_in + n_out)), where N is the number of training examples and α is between 2 and 10. Less data means a smaller network.
    • 
  

  
Then experiment: train, look at the validation loss, and adjust. Too few neurons underfits, so training and validation loss both stay high. Too many overfits: training loss keeps falling while validation loss rises. Regularisation (section 9) lets you use a bigger network safely.

    06
    Loss: measuring how wrong
    
  
    To improve, the network needs a single number that says how bad its predictions are. That's the loss (or cost) function, and training means making it smaller.
    
  
      
    
    • Mean squared error, for regression: MSE = (1/n) Σ (yᵢ − ŷᵢ)². Squaring makes every error positive and punishes big errors heavily.
      • 
    
    • Binary cross-entropy, for a yes/no output between 0 and 1: L = −[ y·ln ŷ + (1 − y)·ln(1 − ŷ) ]. When y = 1 this is just −ln ŷ.
      • 
    
    • Categorical cross-entropy, with softmax over k classes: L = −Σₖ yₖ ln ŷₖ. With a one-hot target that's −ln of the probability given to the correct class.
      • 
  
    
  
    Cross-entropy punishes confident mistakes far harder than squared error does. Predicting 0.01 when the answer is 1 costs −ln 0.01 = 4.6, against a squared error of 0.98. Drag the prediction to compare:

    A useful fact: with a sigmoid output and binary cross-entropy (or softmax and categorical cross-entropy), the gradient of the loss with respect to the output neuron's z simplifies to ŷ − y. That clean result is why those pairs always go together.
    

    



    
  
    07
    Gradient descent
    
  
    The loss depends on every weight. Picture it as a landscape: the weights are your position and the loss is the height. Training is looking for the lowest point.
    
  
    The gradient ∂L/∂w is the slope: how much the loss changes when you nudge w. It points uphill, so step the other way:
    

    w  ←  w − η · ∂L/∂w
    
  
    The learning rate η sets the step size. Too small and training crawls. Too large and each step overshoots the bottom, bounces from side to side, and can fly off entirely.
    
  
    
    
    
      
    
      
    
    
    
    
    
    
      
      
      
      Click the curve to choose a starting point.
    
    
    
    
  
    
  
    On the bowl, L = (w − 1)², any η above 1.0 diverges and anything between 0.5 and 1.0 zig-zags across the bottom. Try the bumpy curve from the right-hand side: the ball settles in a local minimum, a valley that isn't the lowest one. Real networks have millions of weights, and there the bigger nuisances are flat regions and saddle points.
    
  
    Batches, epochs and iterations
    
  
      
    
    • Batch gradient descent: average the gradient over the whole training set, then take one step. Accurate but slow.
      • 
    
    • Stochastic gradient descent (SGD): one step after every single example. Fast and noisy; the noise can help it escape poor valleys.
      • 
    
    • Mini-batch: one step per small group of examples, such as 32. The standard choice.
      • 
    
    • Epoch: one full pass through the training data.
      • 
    
    • Iteration: one weight update, which is one batch.
      • 
  
    

    iterations per epoch = ⌈ N / batch size ⌉
    
  
    On the exam
    10,000 examples, batch size 50, 3 epochs. How many weight updates? 10,000 / 50 = 200 per epoch, × 3 epochs = 600.
    

    



    
  
    08
    Backpropagation
    
  
    Gradient descent needs ∂L/∂w for every weight. Backpropagation computes all of them efficiently by applying the chain rule from the output back towards the input.
    
  
    The chain rule says that if L depends on ŷ, which depends on z, which depends on w, then
    

    ∂L/∂w = ∂L/∂ŷ · ∂ŷ/∂z · ∂z/∂w
    
  
    Each factor is easy on its own. Backprop works out an error signal δ = ∂L/∂z at the output, then passes it back one layer at a time. Each layer reuses the δ of the layer after it, which is why it's fast.
    

    output layer:   δᴸ = ∂L/∂ŷ · f′(zᴸ)
hidden layer:   δˡ = (Wˡ⁺¹)ᵀ δˡ⁺¹ ⊙ f′(zˡ)
gradients:      ∂L/∂Wˡ = δˡ · (aˡ⁻¹)ᵀ        ∂L/∂bˡ = δˡ
    
  
    In words: a weight's gradient is the δ of the neuron it feeds into, multiplied by the value travelling along it.
    
  
    Worked example, step by step
    
  
    A 2-2-1 network with a sigmoid on every neuron, loss L = ½(ŷ − y)² and learning rate η = 0.5. Step through it, or switch on practice mode to work out each number yourself before revealing it. “New numbers” gives you a fresh problem.
    
  
    
    
    
      
      
      
    
    
    
    
    
      
    
      
      
      
      
    
      
  
      
  
      On the exam
      Two easy ways to lose marks. First, use the old weights for the whole backward pass and update everything at the end. Second, the sigmoid's derivative is written in terms of its output, σ(z)(1 − σ(z)), so plug in the activation, not z.
      

      



      
  
      09
      Training in practice
      
  
      Parameters and hyperparameters
      
  
      Parameters are what the network learns: the weights and biases. Hyperparameters are what you choose before training: learning rate, number of layers and neurons, activation function, batch size, number of epochs, regularisation strength.
      
  
      Initialisation
      
  
      Don't start every weight at zero. Every neuron in a layer would compute the same output, receive the same gradient and stay identical forever. Small random starting values break this symmetry. Biases can start at zero.
      
  
        
    
      • Xavier (Glorot) initialisation for sigmoid and tanh: variance 1/n_in, or 2/(n_in + n_out).
        • 
    
      • He initialisation for ReLU: variance 2/n_in.
        • 
  
      
  
      Training, validation and test sets
      
  
      Split your data three ways. Learn the weights on the training set. Use the validation set to choose hyperparameters and to decide when to stop. Touch the test set once, at the very end, for an honest final score.
      
  
      Underfitting and overfitting
      
  
      
    
      
      
      Training lossValidation lossDiagnosisWhat to do
      
      
        
      HighHighUnderfitting: too simple, or not trained long enoughBigger network, train longer, better features
      
        
      LowHigh and risingOverfitting: it memorised the training dataMore data, regularisation, smaller network, early stopping
      
        
      LowLowA good fitCheck once on the test set
      
            
    
      
  
      
  
      Regularisation
      
  
        
    
      • L2 (weight decay): add λ Σ w² to the loss. Keeps weights small, which gives smoother boundaries.
        • 
    
      • L1: add λ Σ |w|. Pushes many weights to exactly zero.
        • 
    
      • Dropout: during training, switch off each neuron at random with probability p (often 0.5). The network can't rely on any single neuron. At test time every neuron is used, with outputs scaled to match.
        • 
    
      • Early stopping: stop when the validation loss stops improving.
        • 
    
      • Data augmentation: make extra training examples, for example flipped or cropped copies of images.
        • 
  
      
  
      Vanishing and exploding gradients
      
  
      Backprop multiplies in one derivative per layer. The sigmoid's derivative is at most 0.25, so through 10 sigmoid layers the gradient can shrink by 0.25¹⁰, roughly a millionth. The early layers then barely learn. That's the vanishing gradient problem. When the factors are larger than 1 the gradient grows instead and training blows up: exploding gradients.
      
  
      Fixes: ReLU activations, Xavier or He initialisation, batch normalisation, residual (skip) connections, and gradient clipping for the exploding case. In recurrent networks, LSTMs were designed to solve it.
      
  
      Better optimisers
      
  
        
    
      • Momentum: keep a running average of past gradients, like a ball rolling downhill with inertia. Smooths out zig-zagging.
        • 
    
      • RMSProp: divide each weight's step by a running average of its recent gradient sizes, so each weight gets its own effective learning rate.
        • 
    
      • Adam: momentum and RMSProp combined. The usual default.
        • 
  
      
  
      On the exam
      Training accuracy is 99% but validation accuracy is 70%. What's happening, and what would you do? Overfitting. Add regularisation (dropout or L2), use early stopping, get more training data, or make the network smaller.

      Things to try
      
  
        
    
      • XOR with no hidden layer. The boundary can only be one straight line, so the loss sticks near 0.69, which is −ln 0.5: a coin flip. Then add a hidden layer of 4 neurons.
        • 
    
      • Or give it a better input. With x₁x₂ as the only input, XOR becomes a single threshold and no hidden layer is needed. Good features can replace layers.
        • 
    
      • Squares make a circle. With x₁² and x₂² as inputs, the output neuron's straight line becomes a circle back in the original plane.
        • 
    
      • Each hidden neuron draws one line. Watch the three hidden squares: each splits the plane with one straight edge. The output neuron combines them into a closed shape.
        • 
    
      • Linear activations can't bend. Two hidden layers of 6, but with linear activation the boundary stays straight. That's the collapse argument from section 3.
        • 
    
      • Learning rate too high. At η = 3 the loss jumps around instead of settling.
        • 
    
      • Learning rate too low. At η = 0.001 it barely moves. Count how many epochs it takes compared with η = 0.1.
        • 
    
      • Overfitting. A few noisy training points and a big network. Training loss heads to 0 while test loss climbs. Then set L2 to 0.01, press Reset weights and train again: the two losses stay closer together.
        • 
    
      • The spiral. Hard: it needs depth and patience. Fast mode is on; give it 20 seconds or so.

      11
      CNNs and RNNs
      
  
      Most first courses end with these two. You usually need the main idea and a couple of formulas.
      
  
      Convolutional neural networks (CNNs)
      
  
      For images. Instead of connecting every pixel to every neuron, a convolutional layer slides a small filter (say 3 × 3) across the image and computes a weighted sum at each position. The same filter weights are reused everywhere, which is called weight sharing. So a layer has very few parameters and spots a pattern wherever it appears. Early layers learn edges; deeper layers learn shapes and then objects.
      
  
        
    
      • Pooling, such as 2 × 2 max pooling, shrinks each feature map by keeping the largest value in each window.
        • 
    
      • A typical CNN: a few rounds of [convolution → ReLU → pooling], then flatten, then dense layers, then softmax.
        • 
  
      

      output size  = (W − F + 2P) / S + 1
conv params  = (F × F × C_in + 1) × C_out
      
  
      W is the input width, F the filter size, P the padding, S the stride, C_in the input channels and C_out the number of filters.
      
  
      
    
      
      
      
      
      
      
      
    
      
    
      
  
      
  
      On the exam
      A 32 × 32 × 3 image goes through 16 filters of size 5 × 5, stride 1, no padding. Output: (32 − 5 + 0) / 1 + 1 = 28, so 28 × 28 × 16. Parameters: (5·5·3 + 1) × 16 = 1,216.
      
  
      Recurrent neural networks (RNNs)
      
  
      For sequences: text, speech, time series. An RNN reads one item at a time and keeps a hidden state that carries memory forward from step to step:
      

      hₜ = tanh( Wₓ·xₜ + Wₕ·hₜ₋₁ + b )
      
  
      The same weights are used at every time step. Training unrolls the loop and runs backpropagation through time, which makes vanishing gradients severe over long sequences. LSTMs and GRUs add gates (forget, input and output gates in an LSTM) that decide what to keep in memory, so they can remember across much longer spans. Transformers, which use attention instead of recurrence, have largely replaced them for text.
